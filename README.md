# alt:V GTA documentation

Documentazione e dati di riferimento relativi a Grand Theft Auto V per il progetto [alt:V](https://altv.mp/).

## Struttura

- `index.md`: pagina di ingresso della sezione GTA.
- `api/`: riferimenti API e dati tecnici.
- `articles/`: articoli su meccaniche e utilizzo degli asset di gioco.
- `toc.yml`: struttura di navigazione della documentazione.
- `tools/`: strumenti di supporto.
- `tools/deps/gta-v-data-dumps`: submodule con i dump dei dati GTA V.

## Sviluppo

Per inizializzare anche la dipendenza esterna:

```bash
git submodule update --init --recursive
```

Per contribuire, mantieni aggiornati i contenuti e verifica i collegamenti/documenti generati dal tooling del progetto prima di aprire una pull request.
